# exp1 - Next.js Web Application

A modern, responsive web application built with Next.js 16, React 19, and Tailwind CSS, featuring a clean navigation interface and multiple pages.

## 📋 Overview

This is a Next.js-based web application that demonstrates a multi-page website with a navigation bar, home page, about page, and contact page. The application features a modern design with dark mode support and responsive layouts.

## ✨ Features

- **Multi-page Navigation**: Easy navigation between Home, About, and Contact pages
- **Dark Mode Support**: Automatic dark mode styling for improved user experience
- **Responsive Design**: Mobile-first responsive layout using Tailwind CSS
- **Modern UI**: Clean and minimal user interface with Tailwind CSS utilities
- **Fast Performance**: Built on Next.js 16 with React 19 for optimal performance

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org) 16.1.3
- **UI Library**: [React](https://react.dev) 19.2.3
- **Styling**: [Tailwind CSS](https://tailwindcss.com) v4
- **Build Tool**: Next.js built-in build system

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/23bai70558/exp1.git
cd exp1
```

2. Install dependencies:
```bash
npm install
```

## 🚀 Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

The page auto-updates as you edit the files.

## 📜 Available Scripts

- `npm run dev` - Runs the app in development mode
- `npm run build` - Builds the app for production
- `npm run start` - Runs the built app in production mode
